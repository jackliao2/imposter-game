Play / Browser

The imposter game browser version is not a port of something you install beside the browser. The page deals the card, stores the two written clues, and collects the vote. Chrome, Safari, Firefox, and Edge are enough. Nothing asks for Flash, an extension, or a permission beyond what a normal site uses for a tap.

Hold works with a finger or a mouse button. On a narrow phone the felt stays inside the width of the window, which is the point of a browser game you pass around rather than a window you sit in front of. Spoken clues can be turned on. They are optional. The slips you can still read at the vote are the default.

Browser, then no signal

The first open needs a connection so the tab can arrive. After that, the saved copy can deal without one. That later state is described on imposter game offline, and it is a different question from which browser you used to get here. Adding the tab to a home screen does not turn it into a store app.

If you were looking for a lobby inside the browser, read why this table has no room code.

Inside the browser tab both written clues remain visible, the vote settles on a slip, and one guess steals the round before you close the tab.

Questions

Which browser plays the imposter game?

Current Chrome, Safari, Firefox, and Edge. The page is the game. There is no plugin.

Is the imposter game browser version different from the app?

There is no app. The browser page deals the word, keeps two written slips, and runs the vote.
