Play / Offline

The imposter game offline works after a finished load, not before. Open the page once on the network you have. The browser keeps the page, the decks, and the fonts. Later, a cabin with no signal can still deal. Refreshing a tab that never finished loading will not.

Imposter game browser means the same thing from the other side: there is no separate program. An imposter mobile game, for this table, is that browser page on a phone. You can add it to the home screen if you want an icon. On an iPhone, share, then Add to Home Screen. On Android, the browser menu has the same kind of item. The icon opens this game, still with no account.

What still needs a network

The first visit. A later visit also likes a network if the page has changed, because the phone will try to fetch the new copy and fall back to the saved one if it cannot. Two written slips from that round stay on the phone with the vote and the secret. They are decided on the device either way. Nothing about the round is sent to a server.

If you are online and want the shorter start notes, use imposter game online.

After the page is saved, both written clues remain for an offline round, the vote uses a slip, and one guess steals the round with no signal.

Questions

Can we play the imposter game offline on a plane?

Yes, if the page was opened and finished loading before you lost the signal.

Does offline include every deck?

Yes. The decks are in the page, not fetched word by word.
