A word game on one phone

If you typed game imposter, game of imposter, or game with imposter, you still want this word table. The imposter game here is a party word game. Everyone sees the same secret except one player. Each person writes a word, the slips stay on the table, and the group votes for the slip that does not belong. A question with an extra word has its own page below, so this page stays the table.
