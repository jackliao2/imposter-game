Play / Compare

Search results for the imposter game settle into two shapes. One is spoken pass-and-play: someone says a word, the word is gone, and later the host reveals a name. The other is a room code: every person opens a second phone, types four letters, and the secret sits on their own screen. This table is neither. Two written clues stay on the felt, the vote is for one of those slips, and a caught imposter gets one guess that can steal the round. There is no room code and no second device.

Spoken clues that are not kept

A spoken round is quick, and it is forgetful. By the time the third player talks, the first clue is an argument about what was said. The imposter's advantage is that memory, not the clue. Switching this table to spoken clues is allowed for a loud room. It is not the default, because the default is the record.

Room codes

A code lobby solves privacy by giving everyone a phone. It also solves a problem this game does not have: the people are already around one table. Waiting for five browsers to join is how a dinner loses the round before it starts. This site does not add matchmaking, accounts, or a code to type.

One trail, played out

The secret is lighthouse.

Crew slips: Maya wrote spiral, then fog. Jordan wrote keeper, then stair. Sam wrote beam, then night.

Imposter slip: Alex wrote sand, then shell.

The vote lands on Alex. Spiral, keeper, beam, and stair belong to a tower in bad weather. Sand and shell belong to a shore. Fog, the wide first clue, could have been either place, so Alex still had a beach in mind when the second word was due. The slip is the evidence. Nobody has to remember who said shell.

The counting, the tie, and the steal guess are on how to play. What the game is, in one definition, is on the imposter game.
